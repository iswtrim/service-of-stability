# 📡 Сервис контроля стабильности голосовых роботов

Сервис автоматического мониторинга качества связи и статусов заданий на обзвон для голосовых роботов. Отслеживает аномалии в исходящих и входящих звонках и оперативно уведомляет в чат Bitrix24.

## ✨ Основной функционал

### 📞 Мониторинг исходящих линий
- Отслеживание аварийных остановок заданий (алерты при статусе `TIMEOUT`).
- Детекция аномалий в звонках: серии `CONGESTION` / `CHANUNAVAIL`, превышение порога `NOANSWER`, единичные ошибки `FAILED`.
- **Умный алертинг:** защита от спама (дедупликация алертов `TIMEOUT`), при которой уведомление по одному инциденту отправляется только один раз.
- **Детализация:** во все уведомления автоматически подставляется номер абонента и точное время инцидента по МСК.

### 📥 Мониторинг входящих линий
- Проверка на отсутствие активности (если за период не было ни одного звонка).
- Превышение порога неотвеченных звонков (`NOANSWER`).
- **Подсчет лидов:** ежедневный подсчет успешных диалогов в выбранных ботах.

### 📊 Отчетность
- **Ежедневная вечерняя сводка:** Отчет по активным заданиям с указанием общего количества звонков по каждому из них. Отправляется в 17:00 МСК только если за день не было критических алертов.

## 🛠 Стек технологий
- **Python 3.13**
- **requests** — выполнение HTTP-запросов к API провайдера и Bitrix24.
- **pytz** — корректная работа с часовыми поясами (МСК).
- **python-dotenv** — безопасное хранение токенов и учетных данных.

## 🔒 Безопасность и архитектура
- **Мультиаккаунтинг:** поддержка нескольких независимых кабинетов одновременно.
- **Отказоустойчивость:** наличие автоматических ретраев (повторных попыток) при сетевых ошибках.
- **Оптимизация API:** кэширование токенов авторизации (снижение нагрузки) и умное формирование запросов (токен запрашивается только при наличии активных ботов).
- **Безопасность:** все чувствительные данные (логины, пароли, вебхуки, URL API) вынесены в переменные окружения (`.env`). 
- **Хранение состояния:** время последнего запуска, кэш токенов и счетчики лидов сохраняются в локальный файл `state.json`, что позволяет скрипту переживать перезапуски без потери данных.
- **Развертывание:** проект оптимизирован для работы на удаленном сервере (VPS) по расписанию (cron).
